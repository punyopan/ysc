# ScaleGap-TH

[English](README.md) | **ภาษาไทย**

**ความทนทานต่อช่องสัญญาณโทรศัพท์ในการตรวจจับเสียงปลอมภาษาไทย มาจากขนาดของโมเดล หรือมาจากการ pretrain แบบ self-supervised — และโมเดลขนาดเท่าโทรศัพท์จะสืบทอดมันมาได้หรือไม่**

ScaleGap-TH เป็นข้อเสนอโครงงานสำหรับ YSC Thailand ที่แยกปัจจัยสองอย่างซึ่งงานวิจัยด้านเสียงปลอมยังพันกันอยู่ วัดผลภายใต้ช่องสัญญาณโทรศัพท์ G.711 แบบควบคุมบนเสียงภาษาไทย และตรวจสอบว่าโมเดลขนาดเล็กที่ได้นั้นรันบนฮาร์ดแวร์ราคาเข้าถึงได้จริงหรือไม่

## คำถามวิจัย

> ความทนทานต่อช่องสัญญาณโทรศัพท์ในการตรวจจับเสียงปลอมภาษาไทย มาจากขนาดโมเดลหรือจากการ pretrain แบบ self-supervised และโมเดลขนาดเท่าโทรศัพท์จะสืบทอดมันได้หรือไม่

### ที่มาของคำถาม

บนข้อมูล benchmark ที่สะอาด ขนาดโมเดลแทบไม่มีผล AASIST ได้ EER 0.83% บน ASVspoof 2019 LA ที่ 297K พารามิเตอร์ ส่วน AASIST-L ได้ 0.99% ที่ 85K [7] นั่นคือลดขนาดลง 3.5 เท่า แลกกับ EER ที่แย่ลงเพียง 0.16 จุด

แต่เมื่อออกจาก benchmark ภาพกลับด้าน โมเดลที่ได้ EER ต่ำกว่า 1% ในโดเมนเดิม กลับขึ้นไปถึง 30–60% บนชุดข้อมูล in-the-wild และ RawNet2 เกิน 40% บนชุดนอกการแจกแจงส่วนใหญ่ ขณะที่ระบบ self-supervised ขนาดใหญ่ยังอยู่ที่ราว 7–9% [20, 21]

**แต่ระบบที่ทนทานเหล่านั้น "ใหญ่" ก็เพราะมันถูก pretrain แบบ self-supervised บนเสียงหลายหมื่นชั่วโมง** ความทนทานจึงอาจมาจากคลังข้อมูล pretrain ไม่ใช่จากจำนวนพารามิเตอร์ และผลก็ไม่ได้เพิ่มตามขนาดแบบตรงไปตรงมา เพราะ Wav2Vec2-AASIST ขนาด 317M พารามิเตอร์ก็ไม่ได้ชนะระบบที่เล็กกว่าเสมอไปบน leaderboard ข้ามชุดข้อมูล [21]

ยังไม่มีใครแยกสองปัจจัยนี้ออกจากกัน และความแตกต่างนี้เป็นตัวชี้ขาดว่าการนำไปใช้บนอุปกรณ์เป็นไปได้หรือไม่:

- ถ้าความทนทานมาจาก **ขนาด** อุปกรณ์คือเพดานที่ข้ามไม่ได้
- ถ้ามาจาก **การ pretrain** โมเดลเล็กที่ผ่านการ distil ก็สืบทอดมันได้ และเพดานนั้นแทบหายไป

มิจฉาชีพเสียงปลอมในไทยติดต่อผ่านโทรศัพท์ ซึ่ง G.711 ตัดความถี่เหนือราว 3.4 kHz ทิ้ง [3] — ย่านที่ร่องรอยของ vocoder ส่วนใหญ่อยู่ โครงงานนี้จึงถามคำถามขนาด-เทียบกับ-pretrain ภายใต้ช่องสัญญาณนั้นโดยตรง

## สิ่งที่มีผู้ตีพิมพ์ไว้แล้ว

ระบุไว้ตั้งแต่ต้นเพื่อไม่ให้กล่าวอ้างเกินจริง รายละเอียดเต็มอยู่ใน [`docs/research-plan.md`](docs/research-plan.md) §2

- **การประเมินโทรศัพท์ภาษาไทยมีอยู่แล้ว** บทความชุดข้อมูล CSS รายงานว่าโมเดลพื้นฐาน "ถูกตรวจสอบในสถานการณ์โทรศัพท์" และชุดข้อมูลรองรับการพัฒนาระบบสำหรับภาษาไทย "ในสถานการณ์โทรศัพท์จริง" [4] และวิทยานิพนธ์ที่เกี่ยวข้องขยายไปถึง channel effects [12] **โปรโตคอลช่องสัญญาณของโครงงานนี้จึงเป็นการทำซ้ำ และระบุไว้เช่นนั้น**
- **เงื่อนไขโคเดกโทรศัพท์จริงมีอยู่แล้ว** — ASVspoof 2021 LA มีการส่งผ่าน PSTN และ PBX ด้วย μ-law และ a-law สำหรับภาษาอังกฤษ [10]
- **ปัญหา threshold transfer ได้รับการพิสูจน์แล้ว** — ระบบที่มี EER 0.21% เมื่อใช้ threshold เดิมกลับปฏิเสธเสียงจริงถึง 78.7% ขณะที่ EER ปลายทางยังอ่านได้ 11.2% [19] **โครงงานนี้ไม่กล่าวอ้างข้อโต้แย้งนั้น** แต่รายงานผลที่ threshold คงที่เป็นการตรวจสอบรอง พร้อมอ้างอิง [19]

## สิ่งที่โครงงานนี้กล่าวอ้าง

1. **การแยกขนาดออกจากการ pretrain** — เป็นสิ่งที่เสนอเป็นหลัก ยังไม่มีงานตีพิมพ์ใดคุมตัวหนึ่งไว้แล้วเปลี่ยนอีกตัวสำหรับความทนทานต่อช่องสัญญาณ
2. **การแยกผลแบนด์วิดท์ออกจาก companding** — เงื่อนไข C1 แยกการตัดความถี่ที่ 3.4 kHz ออกจาก A-law/μ-law companding ยังไม่มีงานใดทำในภาษาใดเลย
3. **การวัดบนอุปกรณ์จริงภายใต้เงื่อนไขช่องสัญญาณสำหรับภาษาไทย**

## การออกแบบ: สามช่อง สองการเปรียบเทียบที่สะอาด

|  | ฝึกจากศูนย์ | pretrain แบบ SSL |
| --- | --- | --- |
| **เล็ก** (<1M) | AASIST-L (~85K) | **Distilled WavLM student** (~1M) |
| **ใหญ่** (>90M) | *(ไม่มีระบบมาตรฐาน)* | WavLM + AASIST back-end (~94M) |

- **ผลของ pretrain โดยคุมขนาดไว้ใกล้เคียงกัน:** AASIST-L เทียบกับ distilled student
- **ผลของขนาด โดยคุม pretrain ไว้:** distilled student เทียบกับ WavLM + AASIST

เส้นทแยงมุมคือการเปรียบเทียบแบบพันกันที่งานวิจัยเดิมรายงาน ซึ่งที่นี่ใช้เป็นการตรวจสอบความสอดคล้องภายใน ส่วนช่องล่างซ้ายที่ว่างเป็นข้อจำกัดที่ระบุไว้ เพราะไม่มีระบบ anti-spoofing ขนาดใหญ่ที่ฝึกจากศูนย์เป็นมาตรฐาน

Student ถูก **distil บนข้อมูลสะอาดเท่านั้น** จึงไม่เคยเห็นช่องสัญญาณเลย ความทนทานใด ๆ ที่มันแสดงออกจึงต้องสืบทอดมาจากตัวแทนเสียง ไม่ใช่เรียนรู้จากการเห็นช่องสัญญาณ

## รูปแบบการทดลอง

![รูปแบบการทดลอง ScaleGap-TH](docs/architecture.svg)

ไฟล์ต้นฉบับที่แก้ไขได้: [`docs/architecture.mmd`](docs/architecture.mmd)

เสียงทดสอบแต่ละไฟล์จะมีเวอร์ชันที่จับคู่กัน 4 เงื่อนไข:

1. **C0 — Clean:** PCM ต้นฉบับที่ 16 kHz
2. **C1 — Bandwidth control:** แปลงเป็น linear PCM 8 kHz แล้วแปลงกลับเป็นอัตราสุ่มของโมเดล
3. **C2 — G.711 μ-law:** เข้ารหัสและถอดรหัสที่ 8 kHz
4. **C3 — G.711 A-law:** เข้ารหัสและถอดรหัสที่ 8 kHz

C1 แยกผลแบนด์วิดท์โทรศัพท์ออกจาก G.711 companding ทุก transformation ใช้กับเสียงจริงและเสียงปลอมเหมือนกัน ผ่าน resampler ชุดเดียวที่ตรึงเวอร์ชันไว้

## สมมติฐาน

- **H1 — ผลของ pretrain (หลัก):** ที่ขนาดเล็กเท่ากัน โมเดลที่ distil มาจะเสื่อมน้อยกว่าโมเดลที่ฝึกจากศูนย์ภายใต้ G.711
- **H2 — ผลของขนาด (หลัก):** ที่ระดับ pretrain เท่ากัน student ขนาดเล็กจะเสื่อมมากกว่าระบบ SSL ขนาดเต็ม
- **H3 — การเสื่อมโดยรวม** ภายใต้ G.711 ในระบบส่วนใหญ่
- **H4 — สัดส่วนจากแบนด์วิดท์:** การเสื่อมมาจากแบนด์วิดท์เท่าใด และจาก companding เท่าใด
- **H5 — ความเป็นไปได้ในการใช้งานจริง:** student ผ่านเกณฑ์ latency และหน่วยความจำที่กำหนดไว้ล่วงหน้าบนอุปกรณ์เป้าหมาย

ทุกผลลัพธ์ให้ข้อมูลที่มีประโยชน์ ถ้า pretrain สำคัญแต่ขนาดไม่สำคัญ → **การ distil เป็นเส้นทางที่ใช้ได้จริงสำหรับงาน edge** ซึ่งเป็นผลที่นำไปใช้ได้มากที่สุด ถ้าขนาดสำคัญแต่ pretrain ไม่สำคัญ → การใช้งานบนอุปกรณ์ถูกจำกัดจริง ถ้าสำคัญทั้งคู่ → ทั้งสองปัจจัยส่งผลแยกกัน

## ผลลัพธ์หลัก

```text
ΔEER_G711(m)    = mean(EER_C2, EER_C3) − EER_C0
DiD_pretraining = ΔEER_G711(AASIST-L)  − ΔEER_G711(student)
DiD_size        = ΔEER_G711(student)   − ΔEER_G711(WavLM + AASIST)
```

การเปรียบเทียบแต่ละคู่ใช้ paired cluster bootstrap ตามไฟล์เสียงต้นทาง ขนาดตัวอย่างจึงเป็นจำนวนไฟล์เสียง ไม่ใช่จำนวนโมเดล ซึ่งเป็นเหตุผลที่การเปรียบเทียบเหล่านี้มีกำลังทางสถิติเพียงพอแม้จะมีระบบไม่มาก

## สิ่งที่โครงงานนี้จะไม่กล่าวอ้าง

- ไม่กล่าวอ้างว่าเสนอ architecture ใหม่ หรือทำสถิติสูงสุดใหม่
- ไม่กล่าวอ้างข้อโต้แย้งเรื่อง threshold transfer ซึ่งเป็นของ [19]
- ไม่กล่าวอ้างว่าเป็นการประเมินโทรศัพท์ภาษาไทยรายแรก ซึ่งเป็นของ [4, 12]
- ไม่กล่าวอ้างว่าสามารถรองรับโมเดลสร้างเสียงที่ไม่เคยพบ
- ไม่กล่าวว่าการจำลอง G.711 เหมือนเครือข่ายโทรศัพท์ไทยจริงทุกประการ
- ไม่ทดสอบ LINE, Discord, WhatsApp, replay, packet loss หรือเสียงรบกวน
- ไม่ใช้คะแนนจากโมเดลเพียงค่าเดียวเป็นหลักฐานยืนยันว่าเสียงจริงหรือปลอม
- ไม่สรุปว่าผลใช้ได้กับผู้พูดภาษาไทยทุกคนหรือ deepfake ในอนาคตทั้งหมด
