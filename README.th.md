# ChannelMoLEx-TH

[English](README.md) | **ภาษาไทย**

**ระบบตรวจจับเสียงปลอมภาษาไทยที่คำนึงถึงช่องทางการส่งสัญญาณและรองรับโมเดลสร้างเสียงที่ไม่เคยพบระหว่างฝึก**

โครงงานนี้เสนอวิธีตรวจจับเสียงสังเคราะห์ภาษาไทย โดยมุ่งลดการเรียนรู้ทางลัดจากชนิดไฟล์ โคเดก แอปพลิเคชัน หรือคุณภาพช่องสัญญาณ เป้าหมายหลักไม่ใช่เพียงทำคะแนนดีบนเสียงปลอมที่คุ้นเคย แต่ต้องลดการตกลงของประสิทธิภาพเมื่อพบทั้ง **โมเดลสร้างเสียงใหม่ × ช่องทางส่งสัญญาณใหม่**

## คำถามวิจัย

> ตัวตรวจจับที่ใช้ WavLM ร่วมกับ Mixture of LoRA Experts และแยกตัวแทนข้อมูลของ “ร่องรอยเสียงสังเคราะห์” ออกจาก “ร่องรอยช่องสัญญาณ” จะจำแนกเสียงจริงกับเสียงปลอมภาษาไทยได้ดีขึ้นหรือไม่ เมื่อเสียงมาจากโมเดลสร้างเสียงและช่องทางส่งสัญญาณที่ไม่เคยพบระหว่างการฝึก

## ขอบเขตที่ต้องทำให้เสร็จ

- เปรียบเทียบ 4 แบบ: frozen WavLM, single-LoRA WavLM, standard MoLEx และ ChannelMoLEx-TH
- ทดสอบอย่างน้อย 2 กลุ่มโมเดลสร้างเสียงที่ถูกกันออกจากชุดฝึก
- ทดสอบ 5 กลุ่มช่องทางจำลอง: โทรศัพท์, Opus, การบีบอัดไฟล์แบบสูญเสียข้อมูล, packet/network impairment และ replay/noise
- แยกผู้พูด บทพูด เสียงอ้างอิง และ checkpoint ระหว่างชุดข้อมูล เพื่อลด data leakage
- ใช้ EER เป็นตัวชี้วัดหลัก พร้อมช่วงความเชื่อมั่นแบบ paired bootstrap
- ตรวจสอบ calibration และรายงานข้อจำกัดอย่างชัดเจน

การทดลองผ่าน LINE/โทรศัพท์/WebRTC จริง งานด้านโทนเสียงภาษาไทย การระบุตำแหน่งเสียงปลอมบางช่วง และ baseline เพิ่มเติมเป็น **เป้าหมายเสริม** เท่านั้น

## เกณฑ์ตัดสินสมมติฐาน

ผลหลักคือ macro-averaged EER ในเงื่อนไขโมเดลสร้างเสียงใหม่ × ช่องทางใหม่ สมมติฐานจะยังไม่ถือว่าได้รับการสนับสนุน หากโมเดลเต็มไม่ดีกว่า baseline ที่แข็งแรงที่สุดอย่างน่าเชื่อถือ หากช่วงความเชื่อมั่นครอบคลุมกรณีที่ไม่ดีขึ้น หรือหากผลดีหายไปเมื่อควบคุม data leakage

## ทรัพยากรคำนวณ

โครงการมีแผนยื่นขอใช้ซูเปอร์คอมพิวเตอร์ **LANTA** ของ ThaiSC หลังเตรียมข้อเสนอ สิทธิ์ใช้ข้อมูล และค่าประมาณทรัพยากรจาก pilot run แล้ว การได้รับสิทธิ์ยังไม่ถูกสมมติว่าแน่นอน หากล่าช้าจะลดการค้นหา hyperparameter ทำเฉพาะการทดลองหลัก และเลื่อนเป้าหมายเสริมทั้งหมด

## จริยธรรมและความเป็นส่วนตัว

จะไม่บันทึกเสียงผู้เข้าร่วม ไม่สร้างเสียงเลียนแบบบุคคลจริง หรือส่งเสียงผ่านแพลตฟอร์ม ก่อนมีความยินยอมและการอนุมัติที่ YSC/SRC/IRB กำหนด ข้อมูลเสียงที่จำกัดสิทธิ์ ข้อมูลระบุตัวตน และ consent records จะไม่ถูกอัปโหลดขึ้น GitHub ระบบนี้เป็นเพียงสัญญาณหนึ่งสำหรับช่วยวิเคราะห์ ไม่ใช่หลักฐานยืนยันว่าเสียงจริงหรือปลอม
