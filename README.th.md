# BenchmarkGap-TH

[English](README.md) | **ภาษาไทย**

**ประสิทธิภาพบนชุดทดสอบเสียงสะอาดสามารถทำนายประสิทธิภาพของระบบตรวจจับเสียงปลอมภาษาไทยหลังผ่านการเข้ารหัสโทรศัพท์ G.711 ได้หรือไม่**

BenchmarkGap-TH เป็นข้อเสนอโครงงานสำหรับ YSC Thailand ที่ลดขอบเขตให้เหลือคำถามเดียว: ระบบตรวจจับที่ทำได้ดีและมีอันดับสูงบนเสียงสะอาด จะยังทำได้ดีและรักษาอันดับเดิมไว้หรือไม่ เมื่อเสียงเดียวกันผ่านช่องสัญญาณโทรศัพท์ G.711 แบบควบคุม

## คำถามวิจัย

> ประสิทธิภาพของระบบตรวจจับบนชุดทดสอบเสียงปลอมภาษาไทยแบบสะอาด สามารถทำนายประสิทธิภาพหลังการเข้ารหัสโทรศัพท์ G.711 แบบ A-law และ μ-law ได้หรือไม่

งานวิจัยก่อนหน้าพบช่องว่างระหว่าง benchmark กับข้อมูลนอกโดเมนอย่างมาก ตัวอย่างเช่น RawNet2 มี EER เพิ่มจาก 3.154% บน ASVspoof 2019 เป็น 37.819% บนชุดข้อมูล In-the-Wild ขณะที่งานด้านช่องทางสื่อสารรายงานว่า EER แย่ลงเฉลี่ย 5.30% หลังเสียงผ่านโคเดก โครงงานนี้จะทดสอบปัญหาดังกล่าวในขอบเขตที่แคบและควบคุมได้สำหรับเสียงภาษาไทย

## รูปแบบการทดลอง

![รูปแบบการทดลอง BenchmarkGap-TH](docs/architecture.svg)

ไฟล์ต้นฉบับที่แก้ไขได้: [`docs/architecture.mmd`](docs/architecture.mmd)

เสียงทดสอบแต่ละไฟล์จะมีเวอร์ชันที่จับคู่กัน 4 เงื่อนไข:

1. **C0 — Clean:** PCM ต้นฉบับที่ 16 kHz
2. **C1 — Bandwidth control:** แปลงเป็น linear PCM 8 kHz แล้วแปลงกลับเป็นอัตราสุ่มของโมเดล
3. **C2 — G.711 μ-law:** เข้ารหัสและถอดรหัสที่ 8 kHz
4. **C3 — G.711 A-law:** เข้ารหัสและถอดรหัสที่ 8 kHz

C1 ใช้แยกผลจากการจำกัดแบนด์วิดท์โทรศัพท์ออกจากผลของ G.711 companding ทุก transformation จะถูกใช้กับทั้งเสียงจริงและเสียงปลอมในลักษณะเดียวกัน

## ระบบตรวจจับที่เปรียบเทียบ

- LFCC-GMM
- AASIST
- frozen WavLM พร้อม classifier
- WavLM พร้อม LoRA adapter หนึ่งชุด

โครงงานเปรียบเทียบระบบตรวจจับที่เป็นตัวแทนของแนวทางต่าง ๆ โดยไม่เสนอ architecture ใหม่ขนาดใหญ่

## ผลลัพธ์หลัก

สำหรับแต่ละระบบคำนวณ:

```text
ΔEER(condition) = EER(condition) − EER(clean)
```

เงื่อนไขหลักคือค่า macro-average ของ G.711 μ-law และ A-law และรายงานเพิ่มเติมดังนี้:

- ช่วงความเชื่อมั่น 95% จาก paired cluster bootstrap ตามไฟล์เสียงต้นทาง
- ผลเมื่อใช้ threshold จาก clean development set โดยไม่ปรับ threshold บน test set
- Spearman rank correlation ระหว่างอันดับบน clean และ G.711
- ความน่าจะเป็นจาก bootstrap ที่ระบบอันดับหนึ่งบน clean ยังคงเป็นอันดับหนึ่งบน G.711

เนื่องจากมีระบบตรวจจับเพียง 4 กลุ่ม สถิติด้านอันดับจะถือเป็น exploratory analysis และต้องรายงานความไม่แน่นอน ไม่อ้างว่าเป็นค่าที่ใช้ได้กับระบบตรวจจับทุกชนิด

## สิ่งที่โครงงานนี้จะไม่กล่าวอ้าง

- ไม่กล่าวอ้างว่าสามารถรองรับโมเดลสร้างเสียงที่ไม่เคยพบ
- ไม่กล่าวว่าการจำลอง G.711 เหมือนเครือข่ายโทรศัพท์ไทยจริงทุกประการ
- ไม่ทดสอบ LINE, Discord, WhatsApp, replay, packet loss หรือเสียงรบกวน
- ไม่ใช้คะแนนจากโมเดลเพียงค่าเดียวเป็นหลักฐานยืนยันว่าเสียงจริงหรือปลอม
- ไม่สรุปว่าผลใช้ได้กับผู้พูดภาษาไทยทุกคนหรือ deepfake ในอนาคตทั้งหมด

การตัดขอบเขตเหล่านี้เป็นความตั้งใจของโครงงาน เพื่อศึกษาคำถามเดียวอย่างรัดกุม: **ประสิทธิภาพบน clean benchmark เทียบกับประสิทธิภาพหลังผ่าน G.711**
